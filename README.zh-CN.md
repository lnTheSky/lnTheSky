## 关于我

我就读于 **HSE MIEM** 的 Computer Security 专业，预计 **2031 年毕业**。我的工作结合了逆向工程、安全测试、原生系统编程和应用机器学习。

- **逆向工程与安全研究** — 二进制分析、软件行为分析、Windows internals 和负责任的漏洞研究。

### LunarAim 2.2 — C++ 重构版

[打开 LunarAim V2 showcase →](https://github.com/lnTheSky/lunar_v2_showdown)

当前世代是一个具有明确 runtime 架构和结构化 frontend bridge 的 **C++ 原生重构版**。项目仍在开发中，尚未进入 EOL。

项目包含：

- 模块化 runtime orchestration 和可观测生命周期；
- 基于 WebView2 的 native UI bridge；
- Win32 Raw Input 和基于 DirectX 的桌面捕获；
- 可替换的 detector、trigger 和 mouse 契约；
- OpenCV/Colorbot 和基于 YOLO 的检测路径；
- 带有动态 GPU 模块边界的 CUDA/TensorRT 集成；
- profiling、telemetry 和以低延迟为目标的 pipeline 设计。

公开仓库是一个 **technical showcase**。生产 runtime 和 proprietary implementation 仍为私有内容。

### LunarEngine Open — Python 前身

[打开归档版 LunarEngine →](https://github.com/lnTheSky/LunarEngine_Open)

旧世代是一个 **Python 3.11 research snapshot**。它记录了早期实验方法：基于 Flet 的桌面 UI、OpenCV 颜色处理、模型辅助检测、以配置为中心的迭代，以及多种 Windows input/output 实验。

该仓库作为归档保存，而不是可用 release。仓库明确说明代码已过时、不受支持，也不用于运行或改造。

## 我的工作方式

我最强的项目会把低层理解与可测量的系统行为结合起来：

1. **理解数据路径。** 逆向相关行为，确定真实输入和输出，并定义可测量的指标。
2. **构建最小实验。** 在嵌入完整 runtime 之前，先独立验证算法或 integration point。
3. **测量每个阶段。** 分别分析 capture、pre-processing、inference、post-processing、control logic 和 output。
4. **从数据中学习。** 准备数据集、训练模型、检查失败案例、比较实验，并把观察转化为具体改动。
5. **端到端集成。** 将结果带入可工作的应用，保留明确边界、诊断能力和替换实现的路径。
