### LunarAim 2.2 — C++ 重构版

[打开 LunarAim V2 showcase →](https://github.com/lnTheSky/lunar_v2_showdown)

当前仍在积极开发的版本：原生 C++ runtime、结构化 WebView2 bridge、模块化 detector/trigger/mouse 契约、Win32 与 DirectX、OpenCV/YOLO 以及 CUDA/TensorRT 加速。公开仓库是 technical showcase，生产实现仍为私有内容。

### LunarEngine Open — Python 前身

[打开归档版 LunarEngine →](https://github.com/lnTheSky/LunarEngine_Open)

旧版 Python 3.11 research snapshot，记录早期的 UI、计算机视觉、配置和 Windows I/O 实验。代码已经过时，仅作为历史和教育参考保存。
