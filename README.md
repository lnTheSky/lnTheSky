### LunarAim 2.2 — C++ redesign

[Open the LunarAim V2 showcase →](https://github.com/lnTheSky/lunar_v2_showdown)

The current, actively developed generation: a native C++ runtime with a structured WebView2 bridge, modular detector/trigger/mouse contracts, Win32 and DirectX integration, OpenCV/YOLO detection, and CUDA/TensorRT acceleration. The public repository is a technical showcase; the production implementation remains private.

### LunarEngine Open — Python predecessor

[Open the archived LunarEngine repository →](https://github.com/lnTheSky/LunarEngine_Open)

The older Python 3.11 research snapshot that documents the project’s earlier UI, computer-vision, configuration, and Windows I/O experiments. It is obsolete and preserved for historical and educational reference only.
